## Firmware-independent PIT units

The later generic-capacity update removes the SM-S921B/BYH2 package-name, PIT-fingerprint, image-digest and model-derived USERDATA-floor gates. Automatic validation matches logical package/live PIT bytes and applies allocation units per selected entry: type 2 eMMC uses 512 bytes and type 8 UFS uses 4096 bytes. Positive caller overrides retain strict route/capacity validation; zero-count USERDATA needs independent caller capacity, and unknown storage types remain unsupported. See [PIT routing](PIT_ROUTING.md).

The shared C ABI advances to 1.10 (65546), preserving twelve exports and 64/537/68-byte request/progress/result layouts. Mixed-storage WRITE results use EJODIN4_FLASH_PER_PARTITION_PIT_UNITS (32) with a zero common-unit field; no capacity-bypass request flag is introduced. The EasyJTAG DLL publication/staging counterpart requires pit-storage-units-v1. Borland still links the engine directly and distributes no engine DLL. This update does not claim measured device sectors or a new physical flash.
